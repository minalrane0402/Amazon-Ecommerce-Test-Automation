# **Amazon-Ecommerce-Test-Automation**
_Amazon Automation Testing using Selenium Webdriver _


##**Project Scope**
This project implements an automated testing suite for Amazon India workflows using Java and Selenium WebDriver. The framework covers core user actions including homepage navigation, manual authentication, product discovery, cart management, and session termination.

##**Test Flow**
1. Open Amazon India
2. Manually log in
3. Search for a product
4. Select a product
5. Add product to cart
6. Open cart and remove product
7. Verify cart state
8. Log out

##**Tools & Tech Stack**
- Java JDK 11+

+ Apache Maven

* Selenium WebDriver

% TestNG

/ ChromeDriver

##**Run Locally**
(Before running the tests, ensure your system is configured with the required dependencies and build tools)
1. Install Java 11 or later and Maven.
2. Clone this repository.
3. Run `mvn test`.
4. Complete Amazon login manually when the browser opens.
